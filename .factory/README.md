# Factory-first worker contract (v1)

The mandatory routing rules are in the root AGENTS.md. They apply to all coding agents and delegated workers, including resumed tasks and child directories. Existing product Bibles, access controls and release gates remain authoritative.

Start: identify the exact repository/worktree and current authority; inspect the owner's authorized factory, matching result cache, live scheduler and qualified worker registry. Choose a dependency-aware plan before paid agent work. Run deterministic work in admitted test/build/browser/search pools. Use qualified cheaper coding workers for bounded tasks only. The primary worker owns difficult decisions and reviews results.

Every delegated job needs an owner, exact source/input identity, scope, allowed write paths, timeout, resource/network class, expected outputs and acceptance criteria. Return a compact receipt with command, exit status, timings and artifact hashes. A queue acknowledgement is not completion. A separate verifier must evaluate the result; reuse valid exact-input evidence rather than duplicate it.

Do not ship an unverified UI, suppress a test, invent an outcome, exceed quotas, expose secrets, bypass access checks, start extra paid agents or mutate production merely to increase utilization. Preserve shared-runner trust boundaries. If the factory is inaccessible, record the attempted supported route and choose a bounded safe fallback. Never claim all future agents are technically forced by a Markdown file: verify the routing receipt for each actual job.

Initialization and validation are provided by the owner's factory policy toolkit. Unknown host addresses, credentials, worker models and budgets must be discovered through existing authorized configuration, not copied from this portable file.
